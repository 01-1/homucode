# HomuCode brand design

## Product name

Spell the full name **HomuCode** with a capital H and C and no space. Use this spelling in UI copy, window and app titles, accessibility labels, and docs. **Homu** is the short form, as in “Sending to a Homu thread.” Use the existing names for T3 Connect, other upstream services, and terminal commands such as `t3`.

## Text wordmark

In headers and other places where the full name is shown, render **HomuCode** as one text label. Give **Homu** the stronger foreground color and **Code** the softer foreground color. Both parts share the same typeface, size, weight, and baseline. Use adjacent text spans with no gap, extra letter spacing at the join, or separate graphic. The accessible name reads HomuCode.

## Compact icon

Use the approved app icon for small marks beside an action, including running Homu actions such as creating a thread or sending to a thread. Keep the action text beside the icon. A row that says “Sending to a Homu thread” uses the icon in its small leading slot. A header that spells out HomuCode uses the text wordmark.
